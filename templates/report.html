CyberShield: AI-Based Cybersecurity Threat Detection Web Application

Download Full Project Report PDF

Abstract

CyberShield is a machine learning based cybersecurity web application developed to classify network traffic as Normal Traffic or Cyber Attack Detected. The system processes 15 network traffic features, stores user-wise prediction history, displays graphical analysis, generates PDF and CSV outputs, scans uploaded files for basic malware risk, and provides chatbot support for project and cybersecurity questions.

Problem Statement

Modern networks generate large amounts of traffic every second. Suspicious traffic bursts, DDoS-style behavior, malicious files, and unauthorized access are difficult to monitor manually. CyberShield solves this by providing a simple web-based platform that combines prediction, storage, visualization, reporting, and access control.

Objectives

  • To detect normal and suspicious network traffic using 15 selected traffic features.
  • To provide a clean web interface for login, prediction, result viewing, and history analysis.
  • To store prediction records with date, time, country, and IP address.
  • To generate chart, PDF report, and CSV export for review and documentation.
  • To include malware scanning and chatbot modules as additional cybersecurity support features.
  • To allow admin users to view registered users and allow or block user access.

System Modules

Login & RegistrationUsers can create accounts and login securely. Passwords are stored using hashing.
HomeIntroduces CyberShield and gives quick access to main project modules.
PredictionAccepts 15 network traffic values and classifies the traffic.
ResultShows classification result, severity, confidence, score, recommendation, country, and IP address.
HistoryDisplays records with chart, graph, PDF download, CSV export, delete, and clear options.
Malware ScannerChecks extension, size, suspicious keywords, SHA-256 hash, and risk score.
ChatbotAnswers cybersecurity questions and questions about all CyberShield project features.
Admin PanelAdmin can view users, detections, scans, and allow or block users.

Advantages

  • Complete user flow from login to prediction and report download.
  • User-wise history storage with chart-based analysis.
  • Admin can control whether users are allowed to access the application.
  • Includes additional cybersecurity modules such as malware scanner and chatbot.
  • Suitable for academic demonstration and project review.

Limitations

The malware scanner uses basic static analysis and does not replace a professional antivirus engine. The traffic prediction quality depends on the trained dataset and selected model features.

Future Enhancements

  • Email-based password reset and OTP verification.
  • Real-time network packet capture integration.
  • Advanced malware signature and sandbox analysis.
  • Role-based reports for admin and normal users.
  • Improved deep learning based threat classification.

Conclusion

CyberShield demonstrates how machine learning, Flask web development, database storage, visualization, reporting, and cybersecurity concepts can be integrated into one practical PG-level academic project.
